PocketArcade firmware installer

Turn an ESP32 into a pocket-sized arcade.

Connect a supported board over USB, select its exact hardware profile, and install PocketArcade from your browser.

Before installing

  1. Use desktop Chrome or Microsoft Edge.
  2. Insert a FAT-formatted microSD card.
  3. Close serial monitors and other programs using the board.
  4. Choose only the profile matching the board and PCB revision.

About erasing

A normal update preserves the ESP32’s NVS settings. Choose a full erase only when troubleshooting or replacing unrelated firmware; it removes device-local settings. SD-card content is separate.

The browser asks permission before accessing a serial device. This page cannot select or flash a port without your confirmation.
