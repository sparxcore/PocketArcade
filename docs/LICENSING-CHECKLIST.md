# Release Licensing Checklist

Use this checklist before publishing a repository release, firmware image, SD-card bundle, or commercial build.

## Core files

- [ ] `LICENSE` contains the unmodified PolyForm Noncommercial License 1.0.0.
- [ ] `NOTICE` is present.
- [ ] Every `Required Notice:` line is intact.
- [ ] The README describes the project as source-available, not OSI open source.
- [ ] The commercial licensing email is `aigenuityltduk@gmail.com`.

## Ownership

- [ ] AIGENUITY LTD owns or controls the rights to original code and assets.
- [ ] External contributors have completed the approved contribution process.
- [ ] Employer-owned or client-owned work has written permission.
- [ ] No confidential code, keys, credentials, or personal data are included.

## Third-party material

- [ ] New dependencies are listed in `THIRD-PARTY-NOTICES.md`.
- [ ] Required third-party licence texts are included.
- [ ] Copyright and attribution notices are preserved.
- [ ] Copyleft or restrictive components have been reviewed.
- [ ] Fonts, icons, sounds, images, and question packs have documented rights.

## Distribution

- [ ] Source archives include `LICENSE` and `NOTICE`.
- [ ] Binary distributions include or reference required notices.
- [ ] The device UI has an About or Licences screen where practical.
- [ ] SD-card game packages identify their own licences.
- [ ] Commercial distributions are covered by a signed commercial agreement.

## Branding

- [ ] Unofficial forks do not present themselves as official PocketArcade releases.
- [ ] Third-party products do not use PocketArcade logos without permission.
- [ ] No unverified registered-trademark claim is used.
